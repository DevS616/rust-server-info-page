# Player Management API - Oxide плагин для Rust

Этот плагин создает REST API для управления игроками на сервере Rust через HTTP запросы.

## Установка

1. **Установите Oxide/uMod на сервер** (если еще не установлен):
   - Скачайте с https://umod.org/games/rust
   - Распакуйте файлы в папку сервера

2. **Загрузите плагин**:
   - Скопируйте `PlayerManagementAPI.cs` в папку `oxide/plugins/`
   - Плагин загрузится автоматически

3. **Настройте конфиг**:
   - После первого запуска откройте `oxide/config/PlayerManagementAPI.json`
   - Измените `API Key` на свой секретный ключ
   - Сохраните файл

4. **Перезагрузите плагин**:
   ```
   oxide.reload PlayerManagementAPI
   ```

## Конфигурация

```json
{
  "API Key": "ваш_секретный_ключ_здесь",
  "API Port": 8080,
  "Listen IP": "0.0.0.0"
}
```

- **API Key** - секретный ключ для аутентификации запросов
- **API Port** - порт для HTTP API (откройте в файрволе)
- **Listen IP** - IP адрес для прослушивания (0.0.0.0 = все интерфейсы)

## Использование через консоль сервера

### Получить список игроков
```
playerapi.list YOUR_API_KEY
```

### Кикнуть игрока
```
playerapi.kick PLAYER_ID "Причина кика" YOUR_API_KEY
```

### Забанить игрока
```
playerapi.ban PLAYER_ID "Причина бана" 1440 YOUR_API_KEY
```
(1440 = 24 часа, 0 = навсегда)

### Заглушить игрока
```
playerapi.mute PLAYER_ID 60 YOUR_API_KEY
```
(60 = 60 минут)

## HTTP API (для будущей версии)

В текущей версии используются консольные команды. Для HTTP доступа нужен дополнительный веб-сервер или плагин-прокси.

## Альтернативное решение: Использование Webrequest плагина

Если нужен полноценный HTTP API, рекомендую использовать плагин **Webrequests** или настроить прокси-сервер на хостинге, который будет вызывать RCON команды.
